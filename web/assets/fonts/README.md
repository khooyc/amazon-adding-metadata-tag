# Bundled web fonts

These Latin subsets are self-hosted so the browser edition keeps its local-first Content Security Policy and does not request fonts from a third party at runtime.

- Bricolage Grotesque — headings, brand text, and navigation labels. [OFL license and source](https://github.com/google/fonts/tree/main/ofl/bricolagegrotesque)
- Hanken Grotesk — body text. [OFL license and source](https://github.com/google/fonts/tree/main/ofl/hankengrotesk)
- Space Mono — tags, eyebrows, and code labels. [OFL license and source](https://github.com/google/fonts/tree/main/ofl/spacemono)

Files were obtained from the Google Fonts CSS API and should remain paired with the licenses in their upstream repositories if redistributed outside this project.
