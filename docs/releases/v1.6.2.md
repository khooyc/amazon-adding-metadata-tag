# Amazon - Adding Metadata Tag 1.6.2

## Windows download

Download and open **Amazon-Adding-Metadata-Tag-Windows-Setup.exe** below. It is a one-click per-user installer that creates Desktop and Start menu shortcuts and launches the app. Node.js, npm, and separate model downloads are not required.

The installer is not currently code-signed. Windows SmartScreen may therefore show a warning. Confirm that you downloaded it from this repository, then choose **More info → Run anyway**. The SHA-256 checksum is also provided in `SHA256SUMS.txt`.

## macOS downloads

- **Amazon-Adding-Metadata-Tag-mac-arm64.dmg** for Apple Silicon (M1 or newer)
- **Amazon-Adding-Metadata-Tag-mac-x64.dmg** for Intel Macs

Open the `.dmg`, drag the app into **Applications**, then Control-click the app and choose **Open** on first launch. These free builds are not Apple Developer ID signed or notarized, so macOS may require confirmation in **System Settings → Privacy & Security**.

## What is included

- Everything from 1.6 and 1.6.1, including image and video review, optional Seller SKU folders, safer metadata writes, versioned backups, crash recovery, and update checking.
- Optional local face and body detection to prioritize likely people images without uploading media.
- English, Simplified Chinese, and Traditional Chinese interfaces, light/dark themes, and a first-run tutorial.
- A bundled ExifTool runtime and bundled detector models, so normal users do not need to install dependencies.
- Stable Windows and macOS installer filenames so the README's latest-download links continue to work for future releases.
