# Amazon - Adding Metadata Tag 1.6.4

## What changed

- People detection now rejects malformed body-pose placeholders that have no usable body box and too few confident keypoints.
- Product-only imagery such as the weighted-vest example no longer becomes a people recommendation from a single low-confidence keypoint.
- Valid smaller people remain detectable through face evidence and anatomically supported body poses.
- The detector version changed so previously cached recommendations are analyzed again with the corrected rules.
- The desktop app can inventory explicitly selected media files as well as complete folders.
- The browser edition can review and write verified XMP metadata to supported video files, and requires each video to be watched fully before it can be selected.
- Browser installation guidance now directs users to the native desktop downloads instead of presenting an unavailable PWA installation flow.
- Self-hosted fonts and website discovery/accessibility improvements were added without introducing external font requests or analytics.

People detection remains advisory. It finds likely people but cannot determine whether a person is AI-generated or whether an image requires the synthetic-performer tag.

## Install

On Windows, download and open **Amazon-Adding-Metadata-Tag-Windows-Setup.exe**. Existing users can install it over the previous version; local settings and review data remain in the app profile.

For local Chrome installation, download **Amazon-Metadata-Tag-Chrome-Extension-v1.6.4.zip**, extract it, enable **Developer mode** at `chrome://extensions`, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.

The free desktop installers are not code-signed. Windows SmartScreen may require **More info → Run anyway**, and macOS may require Control-clicking the app and choosing **Open** on first launch. Confirm that the download came from this repository and use `SHA256SUMS.txt` to verify it.
